Apersepsi

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui: Nama siswa ("Budi"), Kelas ("XI RPL 1"), Umur (16), Nilai (85), Jurusan.

Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program? Tuliskan dugaanmu:

Informasi tersebut disimpan menggunakan variable. Setiap data (nama, kelas, umur, nilai, jurusan) diberi sebuah nama lalu disimpan di memori komputer, sehingga program bisa memanggil dan memakainya kembali kapan saja.

e

Aktivitas 1 — Mengamati

Perhatikan kode berikut:

let nama = "Budi";
let umur = 16;
let nilai = 85;
console.log(nama);
console.log(umur);
console.log(nilai);

1. Apa yang ditampilkan pada Console?

Console menampilkan tiga baris: Budi, 16, dan 85.

2. Menurutmu, apa fungsi nama, umur, dan nilai?

Ketiganya adalah variable, yaitu wadah yang diberi nama untuk menyimpan data. nama menyimpan "Budi", umur menyimpan 16, dan nilai menyimpan 85.

3. Apa yang terjadi jika kode console.log(nama); dijalankan?

Program mengambil isi variable nama lalu menampilkannya di Console, yaitu tulisan Budi.

4. Menurut dugaanmu, apa yang dimaksud dengan variable?

Variable adalah tempat di dalam memori program yang dipakai untuk menyimpan data, supaya data itu bisa dipanggil dan digunakan lagi.

Aktivitas 4 — Eksperimen

1. Apakah hasil pada Console berubah saat data diubah?

Ya, berubah. Console menampilkan data yang paling baru.

2. Bagian kode mana yang kamu ubah?

Nilai yang ada di sebelah kanan tanda sama dengan (=), misalnya "Budi" diganti menjadi "Lutfhi" dan 16 diganti menjadi 17.

3. Mengapa program dapat menampilkan data yang baru?

Karena console.log() menampilkan isi variable saat program dijalankan, bukan tulisan yang tetap. Jadi kalau isi variable diganti, yang tampil ikut berubah.

Aktivitas 6 — Mengenal let dan const

Uji coba let (dapat diubah): Menampilkan angka 17.

Uji coba const (diubah): Menghasilkan Error (TypeError).

KeywordNilai dapat diubah?Kegunaan sederhana
letYa, dapat diubahUntuk data yang nilainya masih mungkin berubah (seperti skor, umur, nilai).
constTidak, tidak dapat diubahUntuk data yang nilainya tetap/konstan (seperti nama sekolah, tanggal lahir).

Aktivitas 7 — Aturan Penamaan Variable

Perhatikan nama variable berikut:

let nama;
let namaSiswa;
let nama_siswa;
let umur2;

Beberapa aturan dasar:

✓ Diperbolehkan

let nama;
let namaSiswa;
let nama_siswa;
let nilai1;

✗ Tidak diperbolehkan

let 1nama;
let nama siswa;
let nama-siswa;

Perhatikan juga

JavaScript membedakan huruf besar dan kecil.

let nama = "Andi";
console.log(nama);

berbeda dengan:

console.log(Nama);
